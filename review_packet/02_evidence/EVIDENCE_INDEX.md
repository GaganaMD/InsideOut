# Evidence index (column definitions only)

## `frozen_results/` (copied from `results/`; produced by the single holdout run and byte-stable since; legacy SD and CRT scores)

| File | What it holds |
|---|---|
| `predictability_map.csv` | Training CV for each construct and feature set. `cv_r2` with `cv_r2_lo/hi` = mean ± 1.96·SD/√5 over 5×5 folds. `mae_gain_pct` is percent; `mae_gain_lo/hi` are in **raw units**. `improves` = `cv_r2_lo > 0` and `mae_gain_lo > 0`. |
| `holdout_predictability.csv` | Test R² and MAE of the training-fit model vs the population-mean baseline (n_test = 616) |
| `holdout_personas.csv` | Per persona × construct:<br>• `train_d`, `distinct_on_train` (pre-registered rule), `test_d`;<br>• `mae_persona` vs `mae_pop` on held-out members;<br>• `gain_pct` (percent);<br>• `gain_lo/hi` = bootstrap 95% CI of the mean reduction in absolute error, in **raw units**;<br>• coverage of the training p10–p90 interval (`cov_persona`, `cov_pop`). |
| `holdout_persona_behaviour.csv` | Held-out Brier scores of persona vs population green-choice rates |
| `saydo.json`, `saydo_primary_terms.csv` | Training say–do model: coefficients and AMEs. Top-tercile decline shares use the cut `green ≥ quantile(2/3)` = 4.0, which includes 41% of training participants because of ties. |
| `holdout_saydo.json` | Held-out log loss and decline shares |
| `age_band_means.csv` | Construct means by age band (train) |
| `p3_selection.csv` | The pre-registered P3 search table (train) |

## `corrected_scores/`
Corrected social-desirability and CRT reruns of the affected analyses. `personas_sd_crt.csv` has the same structure as `holdout_personas.csv` but with corrected scores. It also holds scale verification, reliability, and mis-scoring by age.

## `persona_evidence/`
The full persona tables generated by `src/personas.py build-config`. Tables use legacy SD and CRT values, with a corrected-score block underneath.

## `post_review_corrections.md`
The change log for every post-holdout edit to the submission.
